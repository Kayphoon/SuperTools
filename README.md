# SuperTools

[![CI](https://github.com/Kayphoon/SuperTools/actions/workflows/ci.yml/badge.svg)](https://github.com/Kayphoon/SuperTools/actions/workflows/ci.yml)
[![Release](https://github.com/Kayphoon/SuperTools/actions/workflows/release.yml/badge.svg)](https://github.com/Kayphoon/SuperTools/actions/workflows/release.yml)

`SuperTools` 是面向 **macOS 14+** 的独立原生菜单栏工具应用（纯 Swift / AppKit / ScreenCaptureKit / Vision，二进制仅 ~700 KB，无 Electron / WebView 依赖），集成**低延迟多屏截图、矩形与马赛克标注、本地中英文 Vision OCR** 以及**隐私优先的剪贴板历史管理**。

---

## 核心特性

- **原生多屏截图与标注 (`SuperCapture`)**
  - 基于 `ScreenCaptureKit` 与非激活 `NSPanel` 浮层，支持多显示器独立坐标系与 Retina 缩放，跨屏选区自动按参与显示器的最高倍率合成。
  - 支持框选、平移、八锚点拉伸、方向键 1 pt 微调（按住 `Shift` 加速至 10 pt）。
  - 支持矩形边框标注（`R`，红/黄/蓝三色，2/4/6 pt 线宽）、马赛克不可逆打码（`M`，拖动时实时实心遮挡，确认时在边框绘制前完成 `16×16` 像素化打码）与撤销（`Cmd+Z`）。
  - 支持手动滚动长截图：框选后按 `L`（或点工具栏「长截图」），浮层让出屏幕，用户手动滚动页面，程序以 5 fps 抓取选区并按重叠匹配自动拼接（`ScrollStitcher` 纯函数匹配 + 增量合成，总像素沿用 64 MP 预算）；截过头时往回滚即可撤销多截的尾部，再往下滚会重新接上；选区需完整位于一台显示器内，成品走与普通截图相同的复制 / OCR / 历史流程。不申请任何新权限。
- **本地 Vision OCR**
  - 截图后按确认键即可复制图片（默认 `Enter` 或选区内双击），或仅提取并复制画面文字（默认 `Space`，也可 `Shift+Enter` / `Cmd+C`）；两个确认键都能在偏好设置里重新录制。
  - 不在启动时预热识别器：Vision 会在第一张含文字的图片上懒加载模型（约 30 MB 常驻），而每次截图本就异步跑一次 OCR 建索引，加载开销落在后台；首次手动取字时 HUD 会提示「首次识别需加载模型」。
  - 单任务串行 Actor（`OCRService`），识别期间不堆积原图内存；若后台识别完成时系统剪贴板已被用户新复制内容改写，绝不覆盖当前剪贴板，仅将文字回填至历史索引。
- **隐私优先剪贴板历史 (`SuperClipboard`)**
  - **默认纯内存模式**：文本最多 200 条（UTF-8 上限 16 KiB），图片最多 25 条（仅保留最长边 128 px 的缩略图与上限 32 KiB 的 OCR 文本），默认零磁盘落盘。
  - **敏感内容自动过滤**：自动忽略包含 `org.nspasteboard.ConcealedType`、`org.nspasteboard.TransientType`、`org.nspasteboard.AutoGeneratedType` 或 `de.petermaurer.TransientPasteboardType` 的密码管理器与临时剪贴板内容；启动前已有的剪贴板内容不归档。
  - **有界可选磁盘缓存**：开启后图片按 SHA-256 写入 `~/Library/Caches/com.supertools.app/clipboard/`（目录权限 `0700`，文件权限 `0600`），严格限制最多 25 张、最长保留 7 天、总大小不超过 50 MB；关闭开关或清空历史时立即抹除该子目录。父目录由 macOS 用于 Vision 模型缓存，清理逻辑不会触碰。
- **独立偏好设置与持久化 (`SuperTools`)**
  - 菜单栏内建 `偏好设置…`（`Cmd+,`），支持可视化录制截图快捷键、剪贴板历史快捷键、两个截图确认键（复制图片 / 识别文字）、一键恢复默认快捷键、切换图片历史磁盘缓存、切换选中后自动粘贴，以及隐藏菜单栏图标。
  - 隐藏菜单栏图标后所有快捷键照常可用；需要恢复时再次打开 `SuperTools.app` 即可（第二次启动会把请求转交给已在运行的实例，并弹出偏好设置）。
  - 配置文件以 JSON 持久化于 `~/Library/Application Support/com.supertools.app/settings.json`。

## 快速安装

### 方式一：从 GitHub Releases 下载

前往 [Releases](https://github.com/Kayphoon/SuperTools/releases) 下载最新的 `SuperTools-macos-arm64.zip`，解压后将 `SuperTools.app` 拖入 `~/Applications` 或 `/Applications` 即可运行。

### 方式二：从源码一键编译并安装到 `~/Applications`

系统要求：**macOS 14.0+**，安装 Xcode 或 Xcode Command Line Tools（Swift 6+）。

```bash
git clone https://github.com/Kayphoon/SuperTools.git
cd SuperTools
./scripts/package-mac.sh --install
open ~/Applications/SuperTools.app
```

## 快捷键与操作

| 操作 | 默认按键 |
| --- | --- |
| 呼出截图 | `Cmd+Shift+2`（可在偏好设置中自定义录制） |
| 剪贴板历史面板 | `Cmd+Shift+V`（可在偏好设置中自定义录制） |
| 打开偏好设置 | 菜单栏图标 → `偏好设置…`（`Cmd+,`） |
| 框选 / 移动 / 八锚点缩放 | 鼠标拖动，`V` 切回选区工具 |
| 微移选区 | 方向键（1 pt）；按住 `Shift` + 方向键（10 pt） |
| 矩形标注 / 马赛克打码 | `R` / `M`，随后在选区内拖动 |
| 切换标注颜色（红 / 黄 / 蓝） | `1` / `2` / `3` |
| 切换标注线宽（2 / 4 / 6 pt） | `[` / `]` 或底部工具栏按钮 |
| 撤销上一处标注 | `Cmd+Z` |
| 滚动长截图（框选后） | `L` 或工具栏「长截图」，滚动页面后点「完成」 |
| 确认截图并复制图片 | `Enter` 或选区内双击（可在偏好设置「截图后 · 复制图片」中录制） |
| 仅识别并复制文字 (OCR) | `Space`（也可 `Shift+Enter` / `Cmd+C`；可在「截图后 · 识别文字」中录制） |
| 取消截图 | `Esc` |

## 隐私与性能不变量

1. **按需权限申请**：启动应用不主动弹窗请求屏幕录制或辅助功能权限；仅在首次触发截图时通过 `CGPreflightScreenCaptureAccess()` / `CGRequestScreenCaptureAccess()` 请求屏幕录制权限。全局热键基于 Carbon `RegisterEventHotKey`，无需辅助功能权限。
2. **默认零落盘历史**：未开启图片磁盘缓存前，不在 `~/Library/Caches/com.supertools.app` 创建任何目录或文件；开启后严格执行 25 张 / 7 天 / 50 MB 上限，关闭即删。
3. **敏感内容零记录**：任何包含密码管理器或临时标记的 `NSPasteboardItem` 均被整次忽略。
4. **轻量轮询与有界内存**：剪贴板监控每 250 ms 仅对比 `NSPasteboard.general.changeCount`，无变化时零内容读取、零磁盘扫描；拒绝单边超过 16384 px 或总像素超过 6400 万的超大图进入历史。
