# SuperTools

`SuperTools` 是面向 macOS 14+ 的独立原生菜单栏工具应用（Bundle ID：`com.supertools.app`），提供低延迟屏幕截图、标注（矩形、马赛克）、中英文 Vision OCR 识别以及隐私优先的剪贴板历史管理。

---

## 核心特性

- **原生多屏截图与标注 (`SuperCapture`)**：
  - 基于 `ScreenCaptureKit` 与 `AppKit` 非激活浮层（`NSPanel`），支持多显示器各自坐标与 Retina 缩放，跨屏选区按参与显示器的最高倍率合成。
  - 支持框选、移动、八锚点缩放、方向键微调（`Shift` 加速至 10 pt）。
  - 支持矩形边框标注（`R`，红/黄/蓝三色，2/4/6 pt 线宽）、马赛克不可逆打码（`M`，拖动时实时实心遮挡，确认时在红框绘制前完成 16×16 像素化打码）与撤销（`Cmd+Z`）。
- **本地 Vision OCR**：
  - 支持复制图片并后台异步附加 OCR 索引（`Enter` 或双击），或仅识别并复制文字（`Shift+Enter` 或 `Cmd+C`）。
  - 单任务串行 Actor（`OCRService`），识别期间不排队堆积全尺寸原图；若文字识别期间系统剪贴板已变更，绝不覆盖用户新复制的内容。
- **隐私优先剪贴板历史 (`SuperClipboard`)**：
  - 默认纯内存模式：文本最多 200 条（UTF-8 上限 16 KiB），图片最多 25 条（仅保留最长边 128 px 的缩略图与上限 32 KiB 的 OCR 文本），默认不创建任何原图磁盘缓存。
  - 自动过滤包含 `org.nspasteboard.ConcealedType`、`org.nspasteboard.TransientType`、`org.nspasteboard.AutoGeneratedType` 或 `de.petermaurer.TransientPasteboardType` 的敏感剪贴板内容；启动时已有的剪贴板内容不归档。
  - 可选图片磁盘缓存：开启后后续复制的图片按 SHA-256 保存至 `~/Library/Caches/com.supertools.app/`（目录权限 `0700`，文件权限 `0600`），总预算严格限制在 50 MB（50,000,000 字节）、最多 25 张、最长保留 7 天；关闭开关时立即清理缓存目录。
- **独立设置面板与持久化 (`SuperTools`)**：
  - 菜单栏提供 `偏好设置…`（`Cmd+,`），可随时录制自定义截图快捷键、剪贴板历史快捷键、恢复默认快捷键，以及切换图片磁盘缓存开关。
  - 配置文件以 JSON 持久化于 `~/Library/Application Support/com.supertools.app/settings.json`（目录权限 `0700`，文件权限 `0600`）。

## 快捷键与操作

| 操作 | 默认按键 |
| --- | --- |
| 呼出截图 | `Cmd+Shift+2`（可在偏好设置中自定义） |
| 剪贴板历史 | `Cmd+Shift+V`（可在偏好设置中自定义） |
| 偏好设置 | 菜单栏 → `偏好设置…`（`Cmd+,`） |
| 框选、移动、八锚点缩放 | 鼠标拖动，`V` 返回选区工具 |
| 微移选区 | 方向键；按住 `Shift` 加速至 10 pt |
| 矩形标注 / 马赛克 | `R` / `M`，随后在选区内拖动 |
| 标注颜色（红 / 黄 / 蓝） | `1` / `2` / `3` |
| 标注线宽（2 / 4 / 6 pt） | `[` / `]` 或工具栏按钮 |
| 撤销最后一处标注 | `Cmd+Z` |
| 复制图片 | `Enter` 或选区内双击 |
| 仅识别并复制文字 (OCR) | `Shift+Enter` 或 `Cmd+C` |
| 取消截图 | `Esc` |

## 构建、测试、打包与安装

系统要求：**macOS 14.0+**，安装 Xcode 或 Xcode Command Line Tools（Swift 6+）。

### 1. 运行单元测试

```sh
swift test
```

### 2. 编译 Release 二进制

```sh
swift build -c release
```

### 3. 打包并签名 `dist/SuperTools.app`

```sh
./scripts/package-mac.sh
```

脚本会执行 `swift build -c release`，生成 `dist/SuperTools.app`（`CFBundleIdentifier` 为 `com.supertools.app`），并使用 `codesign` 完成 ad-hoc 签名与严格校验。

### 4. 打包并安装到 `~/Applications/SuperTools.app`

```sh
./scripts/package-mac.sh --install
open ~/Applications/SuperTools.app
```

## 隐私与性能不变量

1. **按需权限申请**：启动应用不主动弹窗请求屏幕录制或辅助功能权限；仅在用户首次触发截图时通过 `CGPreflightScreenCaptureAccess()` / `CGRequestScreenCaptureAccess()` 检查并请求屏幕录制权限。
2. **默认零落盘历史**：未开启图片磁盘缓存前，不在 `~/Library/Caches/com.supertools.app` 创建任何缓存文件；开启后严格执行 25 张 / 7 天 / 50 MB 上限，关闭即删。
3. **敏感内容零记录**：任何包含密码管理器或临时标记的 `NSPasteboardItem` 均被整次忽略。
4. **轻量轮询与有界内存**：剪贴板监控每 250 ms 仅对比 `NSPasteboard.general.changeCount`，无变化时零内容读取、零磁盘扫描；拒绝单边超过 16384 px 或总像素超过 6400 万的超大图进入历史。
